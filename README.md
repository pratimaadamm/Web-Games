# 🎮 Mini Web Games – HTML, CSS & JavaScript  
Built by **Pratima Adam**

This repository contains two fun mini web games built using **HTML, CSS, and JavaScript**.  
They are simple, responsive, and beginner-friendly — perfect for practicing DOM manipulation and game logic.

## 📌 Games Included

### 1️⃣ **Tic Tac Toe**
- Player vs Player mode  
- Dynamic win-check logic  
- Reset game option  
- Clean UI  

**Folder:** `/tic-tac-toe`

---

### 2️⃣ **Rock Paper Scissors**
- Player vs Computer  
- Random computer move  
- Scoreboard  
- Smooth UI  

**Folder:** `/rock-paper-scissors`
